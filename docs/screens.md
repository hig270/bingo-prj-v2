# 画面仕様

決定の経緯は [decisions.md](decisions.md) を参照。【未決】は未決定の論点に依存する部分。

## ホスト側

### 1. トップ
- タイトル
- 「ビンゴ会場を作成」ボタン → モード選択へ
- サービス説明（後回しで可）

### 2. モード選択
- 【未決】特殊モードの仕様が決まってから再設計する（旧実装: スピード 3×3 ／ 普通 ／ カスタム）

### 3. ゲーム設定
- ルーム名
- 景品獲得ライン（ビンゴ n 本で景品獲得。旧実装は 1〜3）
- 景品の数（最後の景品が確定したときの終了確認ダイアログに使う）
- 【未決】特殊モードの設定
- 「募集開始」ボタン → 募集画面へ

### 4. 募集画面
- ルーム名
- 参加用 QR コード（大きく表示）
- 参加人数と参加者名の一覧（リアルタイム更新）
- 「ゲーム開始」ボタン → 確認ダイアログ → ゲーム画面へ（プレイヤー側も自動で遷移）

### 5. ゲーム画面（操作と投影を兼ねる1画面）
- 抽選ボタン
- 抽選番号の演出表示
- **抽選履歴（常時表示）**
- 参加人数、景品の残り数
- ランキング表（順位が確定していない人のみ。期待抽選回数の小さい順、同値は同順位）
- 上位3人・下位3人のカード（プレイヤーが開けた状態で表示）
- リーチ・ビンゴ・景品獲得した人の名前の表示
- 順位決定ゲーム（同時ビンゴが発生したとき）
  - 対象者と、割り当てられた番号（1〜75、76人以上なら重複あり）
  - 抽選ボタン（本抽選とは別の箱）と抽選番号
  - 距離の近い順の結果。同じ距離の人がいれば再戦
  - 進行中は本抽選を一時停止する
- 「ゲーム終了」ボタン
- 最後の景品が確定したとき「ゲームを終了しますか？」ダイアログ

### 6. 結果画面
- 最終ランキング
  - 景品獲得者: 景品獲得ラインに達した抽選回の早い順、同じ回なら順位決定ゲームの結果
  - 未獲得者: 終了時点のゲーム中ランキングの順で、獲得者の後ろに並ぶ
- 最下位の人のカード

## プレイヤー側

### 7. 参加画面
- ルーム名
- 名前の入力（ルーム内で重複禁止）
- 「参加」ボタン → 待機画面へ
- 【未決】再接続の方法（認証の論点）

### 8. 待機画面
- 参加完了の表示、ルーム名、自分の名前
- ゲーム開始で自動的にゲーム画面へ

### 9. ゲーム画面
- 左上: キャラクター
  - タップすると画面上部に吹き出しで雑談（数秒で消える）
  - 最新の抽選番号を吹き出しで伝える（抽選された瞬間の演出も行う）
  - リーチ・ビンゴ・順位決定ゲームの開始なども吹き出しで伝える（派手な演出は後で検討）
  - 開け忘れがあるまま次の抽選が始まったら「開け忘れがあるかも」の吹き出しを、開け忘れがなくなるまで表示し続ける。この間はタップしても何も起こらない
- 右上: 接続状態の表示（再接続中であることが分かる）
- 右上: メニュー
  - ルーム名
  - ルールの確認（景品獲得ラインなどを日本語で表示）
  - 抽選履歴を確認 → 履歴ダイアログ
- 自分の情報
  - A. 景品獲得ラインまでの期待抽選回数
  - B. 次の抽選でビンゴ（新しいライン1本）する確率
  - C. 5回以内にビンゴ（新しいライン1本）する確率
  - D. 順位（順位が確定していない人の中での順位。例: #12 / 300人）
  - E. 景品獲得ラインの進み具合（例: ビンゴ 1 / 2）
  - F. 次の抽選番号が自分のカードに当たる確率
  - G. 次の抽選で景品獲得ラインに達する確率（景品獲得ラインが2本以上のときのみ）
  - H. 5回以内に景品獲得ラインに達する確率（同上）
  - 景品獲得後は A・G・H を「—」にし、確定した順位を表示する
- カード
  - カードの上にプレイヤー名
  - マスは手動でのみ開ける。当選マスの強調表示・自動オープンはしない
  - 抽選されていない番号のタップは受け付けない
  - ラインの最後のマスを押した瞬間にビンゴ成立
  - 景品獲得後も開け続けられる
- 順位決定ゲームの表示
  - 対象者: 自分の番号、抽選番号、結果
  - 対象外の人: 順位決定ゲームが進行中であること（本抽選の一時停止中）

### 10. 結果画面
- 全体の最終ランキング（ホストの結果画面と同じ内容）
